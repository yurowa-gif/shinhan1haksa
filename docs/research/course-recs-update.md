# 권장 이수 과목 자료 매년 갱신 절차 (RS4)

대학은 보통 대입 2~3년 전 상반기(예: 2028학년도 자료는 2025년 6월 전후)에 권장 과목을 발표하고, 그 뒤 고치기도 한다. **매년 한 번(권장 시기: 2~3월, 새 학년 수강 신청 전)** 아래 순서로 갱신한다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `data/course_recommendations/course_recommendations.csv` | 본 자료. 한 줄 = (기준 연도, 대학, 모집단위) |
| `data/course_recommendations/sources.csv` | 출처 문서 목록(문서명·발행 기관·URL·발행일·열람일·쪽) |
| `data/course_recommendations/course_name_map.csv` | 대학 문서 표기 → 표준 과목명 |
| `data/course_recommendations/standard_courses_2022.csv` | 2022 개정 표준 과목명 |

과목은 `;`로 구분한다. 파일은 UTF-8(BOM 없음)으로 저장한다(엑셀로 열고 저장하면 BOM이 붙으니 "CSV UTF-8"이 아닌 편집기나 구글 시트 → CSV 내려받기를 쓴다).

## 순서

1. **새 문서 찾기** — 대상 대학 입학처 공지와 대교협 어디가(adiga.kr) 자료실에서 "○○학년도 권장 과목"을 찾는다. 대상 대학과 허용 도메인은 `course-recs-plan.md` 2·5절.
2. **출처 등록** — `sources.csv`에 한 줄 추가. `retrieved_at`은 내려받은 날(YYYY-MM-DD), `page`는 표가 있는 쪽. PDF 파일은 저장소에 넣지 않는다.
3. **행 추가** — 새 기준 연도는 **새 행으로 추가**하고 이전 연도 행은 지우지 않는다(이전 자료를 쓰는 학년이 있을 수 있다). 같은 기준 연도 자료를 대학이 고친 경우에만 그 행을 고친다.
   - 과목 칸 규칙은 `course-recs-plan.md` 4.1절(구분 없음 → 권장 칸, 이름이 나온 조건 과목은 칸에, 예시는 note만, 단과대 단위는 unit에 단과대)
   - 핵심·권장 구분 없음 → 모두 `recommended_courses`
   - 미제시 → 두 과목 칸 빈칸
   - 조건형("과학 진로선택 3과목 이상", "A, B 중 1과목 이상") → 원문 그대로 `note`. 조건에 이름이 나온 과목은 과목 칸에도 넣는다
4. **과목명 맞추기** — 문서 표기가 표준과 다르면(`확률과통계` 등) `course_name_map.csv`에 추가. 하나로 대응되지 않는 과목은 넣지 말고 `needs-check.md`에 적는다.
5. **검사** — `npm test research`. 헤더, 빈 출처, 허용 도메인, 중복 행, 과목명, 개인정보 패턴을 검사한다.
6. **바뀐 행 확인** — PR 화면의 파일 변경(diff)에서 CSV 줄 단위로 보인다. 로컬에서는:
   ```
   git diff main -- data/course_recommendations/course_recommendations.csv
   ```
   `-`줄은 지워지거나 바뀐 행, `+`줄은 새 행이다. 같은 (기준 연도, 대학, 모집단위)에 `-`와 `+`가 함께 있으면 대학이 고친 것이므로 PR 설명에 "○○대 ○○학과 권장 과목 변경"을 적는다.
7. **PR** — 대학 묶음마다 PR 하나. PR 설명에 출처 문서와 바뀐 대학 목록.
8. **앱 반영(6단계 이후)** — 병합되면 관리자가 설정 스프레드시트 `course_recommendations` 탭에 CSV를 붙여 넣는다(열 순서 같음). 붙여 넣는 기능·검사는 F15 구현 때 정한다. 가정: 탭 전체를 바꿔 넣는다(행 단위 병합 없음).

## 하지 않는 것

- 학원·블로그·언론 요약으로 채우지 않는다. 공식 원문이 없으면 `needs-check.md`.
- 추측으로 과목을 채우지 않는다.
- 학생 정보와 섞지 않는다(이 자료는 대학 공개 정보뿐).
