## 3. 기준 연도(`base_year`) 정의 — 제안

- **`base_year` = 그 자료가 적용되는 대입 학년도**(문서 제목의 "2028학년도"). 발표 연도가 아니다.
- 우리 학교 학생과의 대응(모두 2022 개정 교육과정):

| 입학 연도 | 대입 학년도 | 비고 |
| --- | --- | --- |
| 2025 | 2028 | 지금 2학년 |
| 2026 | 2029 | 지금 1학년 |
| 2027 | 2030 | 2027년 3월 입학 |

- 가정: 학생의 대입 학년도 자료가 아직 없으면(예: 2029·2030) **가장 가까운 이전 base_year 자료를 보여 주고 "○○학년도 기준 자료"라고 표시**한다. 앱 쪽 표시 규칙은 F15 구현 때 총괄이 확정한다.

## 4. 핵심·권장 구분이 없는 대학

대학마다 표현이 다르다(핵심/권장, 권장만, "권장하는 과목", "미제시").

| 원문 | CSV 처리 |
| --- | --- |
| 핵심과 권장을 나눔 | `core_courses`, `recommended_courses`에 나눠 넣는다 |
| 구분 없이 "권장"만 | 모두 `recommended_courses`, `core_courses`는 비운다(핵심으로 올리지 않는다) |
| 모집단위가 "미제시"(진로에 따라 자유 선택) | 행을 넣고 두 과목 칸을 모두 비운다. `note`에 원문 안내를 쓴다. 앱은 "대학이 과목을 제시하지 않음"으로 보여 준다 |
| 과목이 아닌 조건(예: "과학 진로선택 3과목 이상", "A, B, C 중 2과목 이상") | 조건 문장을 **원문 그대로 `note`에** 쓴다. 조건에 과목이 이름으로 나오면("A, B, C 중") 그 과목들은 `recommended_courses`에도 넣는다. 이름 없이 "관련 과목"이라고만 하면 문서에 그 정의가 있을 때만 풀어 쓴다 |
| 계열 단위로만 발표(예: "자연계열 전체") | `unit`에 원문 계열명을 그대로 쓴다(예: `자연계열 전체`) |

### 4.1 과목 칸 규칙 (2026-11-07 총괄 결정, #44 검증 후)

1. **대교협 xlsx에서 핵심·권장 칸이 하나로 병합된 행**은 구분 없음으로 보고 과목을 모두 `recommended_courses`에 넣고 `core_courses`는 비운다. note는 원문이 표준 과목명뿐이어도 늘 `반영과목(원문, 핵심·권장 구분 없음): …`으로 시작한다. (1차 대학 문서 행 — 연세·중앙·부산 — 은 `rs3-notes.md` 공통 절 설명으로 갈음한다: 세 문서 모두 구분 없음 → 권장 칸.)
2. `A 또는 B`, `[A, B, C 중 N과목]`, 비고의 `…을 포함하여`처럼 **이름이 나온 과목은 모두 과목 칸에** 넣고, 조건은 note에 원문 그대로 둔다.
3. `그 외는 희망 진로에 따라 … 등`처럼 **예시로 든 과목은 과목 칸에 넣지 않는다**(note에만).
4. 단과대 단위로 적용되는 `전 모집단위`, `…제외 모집단위`, `… 진로희망자`는 `unit`에 단과대 이름을 붙인다(예: `경북대 사회과학대학 전 모집단위`).
5. 공식 자료에 같은 모집단위가 유형이 다른 두 줄로 있으면 같은 이름으로 두 줄을 두고 note에 `공식 자료에 유형이 다른 두 행`을 쓴다(서울대 식품영양학과·의류학과).
6. 원문 표기가 표준과 다른 과목(대응표 사용, 괄호 단서 `지구과학(행성우주과학 불요)`, 쉼표 누락 `법과 사회 정치`)은 표준 과목을 칸에 넣고 원문을 note에 남긴다.

검사기(`tests/research/course_recs_check.js`)가 1번 일부(note가 `반영과목(원문, 핵심·권장 구분 없음)`으로 시작하면 `core_courses`는 빈칸), 2번(note의 또는·중 N과목·포함 → 과목 칸), 5번을 검사한다. 1번의 "병합 행이면 머리말이 있다"는 CSV만으로는 병합 여부를 알 수 없어(병합이 아닌데 핵심이 '-'인 행도 core가 빔) 검사하지 못한다.

## 6. 수집 규칙

1. 공식 문서만 쓴다. 2차 자료뿐이면 `docs/research/needs-check.md`("확인 필요" 목록)에 둔다. 추측으로 채우지 않는다.
2. 내려받은 PDF는 커밋하지 않는다(저작권·용량). `sources.csv`에 문서명·발행 기관·URL·발행일·열람일·쪽만 남긴다.
3. 원문의 과목 표기(띄어쓰기, Ⅰ/I 등)가 표준 과목명과 다르면 `course_name_map.csv`에 원문 → 표준을 남긴다. 2015 개정 과목명(예: 물리학Ⅱ)처럼 하나로 대응되지 않는 것은 대응하지 않고 확인 필요로 둔다.
4. 개인정보는 다루지 않는다(대학 문서에도 없지만, 테스트가 이메일·전화번호 패턴을 검사한다).
5. 대학 묶음마다 PR 하나.
