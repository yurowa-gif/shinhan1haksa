# 7단계(학생·학부모 기능) 작업 분담안

> 2026-11-19 총괄. 근거: 결정 82·83, PRD 5절 F9·F10·F14, 6.1. 0단계 진단 전이므로 **신원 판정은 한 곳**(지금은 6.1의 1안: 접속 이메일 → `users` → `students.email`·`guardian_links.parent_email`)에 모으고, 진단 결과가 2·3안이면 그 한 곳만 바꾼다.

## 1. 원칙
- 학생은 **본인**, 학부모는 **연결된 자녀**만. 판정은 서버(`requirePermission_` scope student의 isOwn·isGuardian). 화면 숨김은 보안이 아니다.
- 학생·학부모 응답에 넣지 않는 것: 다른 학생, 전화번호, 상담 **내용**(학부모는 날짜·교사만, `show_to_parent`가 참일 때), 교사 메모·OUT 입력자 이메일, 감사 기록.
- 상담 신청·합의 사항(F17)은 6단계. 이번에는 하지 않는다.
