# 0단계 확인 체크리스트

PRD 11절 0단계 완료 기준: **교사·학생·학부모 시험 계정이 각자 홈만 본다. 학부모 이메일 식별 방식 확정.**

준비: README의 "처음 설치" ①~⑧ 완료(⑥ `setup`, ⑦ 스크립트 속성·`seedFakeData`, ⑧ 배포), `/exec` URL 확보. 시험 계정마다 **시크릿 창**을 따로 열어 확인한다.

## A. 데이터 파일
- [ ] 내 드라이브에 `신한1학사_운영DB`, `신한1학사_상담일지`, `신한1학사_설정` 3개가 있다.
- [ ] 세 파일 모두 공유 상태가 "나만"이다(공유 아이콘 없음).
- [ ] 운영DB 탭: `users, terms, students, enrollments, guardian_links, audit_log`. 각 탭 첫 열 `id`, 끝 4열 `created_at, created_by, updated_at, updated_by`.
- [ ] `setup`을 한 번 더 실행해도 탭·데이터가 그대로다(로그에 `[유지]`, `[탭 유지]`).
- [ ] `students` 30명, 이름 옆 메모가 "가짜 데이터"다.

## B. 로그인 검증(가장 중요, PRD 6.1)
각 계정으로 `/exec?page=diag` 를 연다.

| 계정 | 접속자 이메일 | "다시 확인" 버튼 결과 | 등록 여부 |
| --- | --- | --- | --- |
| 내 교사 계정(소유자) | | | |
| 시험 학생(개인 gmail) | | | |
| 시험 학부모(개인 gmail) | | | |
| 등록 안 된 아무 gmail | | | |

- [ ] 개인 gmail에서 "접속자 이메일"이 실제 주소로 나온다 → **같은 웹앱으로 운영**(1안 확정).
- [ ] (빈 값)으로 나온다 → 1안 실패. 화면을 캡처해서 알려 주세요. 다음 대화에서 2안(학생·학부모용 별도 웹앱 + 신원 토큰)을 만든다.
- [ ] README ⑧ 배포 화면에서 "Google 계정이 있는 모든 사용자"를 고를 수 있었다(학교 도메인 정책으로 막혀 있으면 알려 주세요).
- 결과를 어떻게 판단하는지는 아래 **F절** 표를 본다.

## C. 역할별 홈(`/exec`)
- [ ] 소유자: 관리자 홈(전체 현황 숫자) + 위쪽에 "관리자 / 학사 교사" 전환 탭. 학사 교사 탭에 내 담당 학생 목록.
- [ ] 시험 학생: 내 정보 카드(가짜 1번 학생)만 보인다. 다른 학생 이름이 없다.
- [ ] 시험 학부모: 자녀 전환 탭 2개(형제). 탭을 누르면 각 자녀 카드가 바뀐다.
- [ ] (선택) 시험 학사교사: 담당 학생 목록만.
- [ ] (선택) 시험 담임: 우리 반 학사생만.
- [ ] 등록 안 된 계정: "권한이 없습니다" 화면만.

## D. 권한은 서버에서 막히는가
- [ ] 시험 학생으로 `/exec?role=admin` 을 열어도 학생 홈이 나온다.
- [ ] 시험 학부모 창에서 F12 콘솔에 아래를 입력하면 "권한이 없습니다" 오류가 난다(남의 학생 id).
  ```js
  google.script.run.withFailureHandler(e=>console.log(e.message)).getStudentSummary('bbbbbbbb-0000-4000-8000-000000000005')
  ```
  (Apps Script 화면은 iframe 안에 있으므로 콘솔 상단의 실행 컨텍스트를 `userCodeAppPanel`로 바꾼 뒤 입력)
- [ ] 같은 방법으로 `getHomeData('admin')` → "권한이 없습니다".
- [ ] 운영DB `audit_log` 탭에 `denied:...` 행이 남아 있다(누가, 언제, 무엇을).

## E. 휴대폰
- [ ] 휴대폰 세로 화면에서 글씨·버튼이 충분히 크고 가로 스크롤이 없다.

## F. 결과로 1·2·3안 정하기 (PRD 6.1)

B절 표를 채운 뒤, 아래 표에서 맞는 줄을 찾습니다. 계정 이름은 예시이며 실제 주소는 문서에 적지 않습니다(예: `시험용gmail@gmail.com`).

| 확인한 결과 | 판단 | 다음 할 일 |
| --- | --- | --- |
| 개인 gmail로 `/exec?page=diag` → "접속자 이메일"이 **실제 주소**로 나오고, "다시 확인" 버튼 결과도 **같은 주소** | **1안**: 웹앱 하나로 교사·학생·학부모 모두 운영 | C~E절 계속 진행 |
| 개인 gmail은 **(빈 값)**, 학교 계정(소유자·시험 교사)은 정상 | **2안**: 학생·학부모용 별도 웹앱("접속한 사용자로 실행")을 만들고, 그 웹앱이 `ScriptApp.getIdentityToken()`으로 받은 신원 토큰을 붙여 본 웹앱에 데이터를 요청 | 캡처를 보내 주면 다음 대화에서 2안을 만듭니다 |
| 2안도 안 됨: 개인 gmail이 별도 웹앱에 **접속 자체가 막힘**, 또는 본 웹앱이 **토큰 검증에 실패** | **3안**: 관리자가 발급하는 개인 열람 링크(서명·만료 포함). 동의도 링크 화면에서 받음 | 2안 시험 결과 캡처를 보내 주세요 |
| README ⑧ 배포 화면에 **"Google 계정이 있는 모든 사용자"** 항목이 없음 | **1·2안 모두 막힘**(학교 밖 계정이 웹앱을 열 수 없음) | 학교 Workspace 관리자에게 "외부 Google 계정의 웹앱 접근 허용"을 문의하거나, 바로 3안으로 |

**보내 줄 것**: 계정마다 `/exec?page=diag` 화면 캡처 1장씩(B절 표의 4개 계정). "다시 확인" 버튼을 누른 뒤의 화면이어야 합니다. 캡처에 나온 실제 이메일 주소는 가려도 됩니다. 주소가 나왔는지(빈 값인지)만 알면 됩니다.
