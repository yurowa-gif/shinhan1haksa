# 0단계 확인 체크리스트

PRD 11절 0단계 완료 기준: **교사·학생·학부모 시험 계정이 각자 홈만 본다. 학부모 이메일 식별 방식 확정.**

준비: README의 "처음 설치" ①~⑧ 완료(⑥ `setup`, ⑦ 스크립트 속성·`seedFakeData`, ⑧ 배포), `/exec` URL 확보. 시험 계정마다 **시크릿 창**을 따로 열어 확인한다.

## A. 데이터 파일
- [ ] 내 드라이브에 `신한1학사_운영DB`, `신한1학사_상담일지`, `신한1학사_설정` 3개가 있다.
- [ ] 세 파일 모두 공유 상태가 "나만"이다(공유 아이콘 없음).
- [ ] 운영DB 탭: `users, terms, students, enrollments, guardian_links, audit_log`. 각 탭 첫 열 `id`, 끝 4열 `created_at, created_by, updated_at, updated_by`.
- [ ] `setup`을 한 번 더 실행해도 탭·데이터가 그대로다(로그에 `[유지]`, `[탭 유지]`).
- [ ] `students` 30명, 이름 옆 메모가 "가짜 데이터"다.

- [ ] (빈 값)으로 나온다 → 1안 실패. 화면을 캡처해서 알려 주세요. 다음 대화에서 2안(학생·학부모용 별도 웹앱 + 신원 토큰)을 만든다.

## C. 역할별 홈(`/exec`)
- [ ] 소유자: 관리자 홈(전체 현황 숫자) + 위쪽에 "관리자 / 학사 교사" 전환 탭. 학사 교사 탭에 내 담당 학생 목록.
- [ ] 시험 학생: 내 정보 카드(가짜 1번 학생)만 보인다. 다른 학생 이름이 없다.
- [ ] 시험 학부모: 자녀 전환 탭 2개(형제). 탭을 누르면 각 자녀 카드가 바뀐다.
- [ ] (선택) 시험 학사교사: 담당 학생 목록만.
- [ ] (선택) 시험 담임: 우리 반 학사생만.
- [ ] (선택) 출결 담당: 편집기에서 `addUser('시험용gmail@gmail.com', '시험 출결담당', 'attendance')` 실행 후 그 계정으로 열면 "출결 담당" 홈(오늘 날짜·학사생 수)이 보인다.
- [ ] 등록 안 된 계정: "권한이 없습니다" 화면만.

## D. 권한은 서버에서 막히는가
- [ ] 시험 학생으로 `/exec?role=admin` 을 열어도 학생 홈이 나온다.
- [ ] 시험 학부모 창에서 F12 콘솔에 아래를 입력하면 "권한이 없습니다" 오류가 난다(남의 학생 id).
  ```js
  google.script.run.withFailureHandler(e=>console.log(e.message)).getStudentSummary('bbbbbbbb-0000-4000-8000-000000000005')
  ```
  (Apps Script 화면은 iframe 안에 있으므로 콘솔 상단의 실행 컨텍스트를 `userCodeAppPanel`로 바꾼 뒤 입력)
- [ ] 같은 방법으로 `getHomeData('admin')` → "권한이 없습니다".
- [ ] 운영DB `audit_log` 탭에 `denied:...` 행이 남아 있다(누가, 언제, 무엇을).

## E2. 기기·브라우저 확인(실기기 13가지)

> 2026-11-20 추가. 근거와 자세한 설명은 `docs/design/device-compat.md`. 클라우드 세션은 실제 휴대폰을 만질 수 없어서 선생님 확인이 꼭 필요하다.
> **가장 중요한 것은 K1~K3(카카오톡)과 M1(계정 여러 개)이다.** 학생·학부모가 링크를 카톡으로 받기 때문에, 여기서 막히면 앱을 아예 못 연다.
> 각 줄: **할 일 → 이렇게 보이면 통과 → 안 되면 보내 줄 것.** 사진이 "필수"인 줄은 통과해도 한 장 찍어 주세요(실제 이메일 주소·이름은 가려도 됩니다).

준비
- 시험 학생 계정(개인 gmail)이 로그인된 **아이폰 1대**, **안드로이드 휴대폰 1대**(삼성 갤럭시면 좋음), **윈도우 노트북 1대**.
- 앱 주소(`/exec`)를 선생님 카카오톡 **나와의 채팅**에 보내 둔다(K1~K3에서 씀).

### 카카오톡으로 받은 링크(학생·학부모가 실제로 여는 길)

| # | 할 일 | 이렇게 보이면 통과 | 안 되면 보내 줄 것 | 사진 |
| --- | --- | --- | --- | --- |
| K1 | **아이폰** 카카오톡 → 나와의 채팅 → 앱 링크를 누른다(카톡 안에서 열림) | Google 로그인 뒤 시험 학생의 홈이 보인다 | 멈춘 화면 사진. 특히 "403", "disallowed_useragent", "이 브라우저 또는 앱은 안전하지 않을 수 있습니다" 같은 글자가 보이면 꼭 | 필수 |
| K2 | **안드로이드** 카카오톡에서 같은 일 | K1과 같음 | K1과 같음 | 필수 |
| K3 | K1·K2에서 막혔으면: 카톡 안 브라우저의 메뉴(화면 오른쪽 위나 아래의 `⋮` 또는 `⋯`)에서 **다른 브라우저로 열기**를 누른다. 메뉴가 없으면 링크를 **길게 눌러 복사** → Safari(아이폰)·Chrome 또는 삼성 인터넷(안드로이드)을 열어 주소창에 **붙여넣기** | 로그인 뒤 홈이 보인다 | 메뉴에 실제로 보이는 글자(예: "Safari로 열기", "다른 브라우저로 열기")를 사진으로 — 아래 안내 문구를 실제 메뉴 이름에 맞게 고친다 | 필수 |

> K1·K2가 **통과**하면: 아래 안내 문구는 쓰지 않아도 됩니다.
> K1·K2가 **막히고 K3가 통과**하면: 링크를 보낼 때 아래 안내 문구를 함께 보냅니다(가정통신문·카톡 공지). 코딩 세션은 앱 안에서도 같은 안내를 띄우는 일을 합니다.

**학부모 안내 문구 — 안드로이드(갤럭시 등)**

> 카카오톡에서 링크를 누르면 카카오톡 안에서 열려 구글 로그인이 되지 않을 수 있습니다.
> 아래 순서로 열어 주세요.
> 1. 링크를 누른 뒤 화면 오른쪽 위 **⋮**(점 세 개)를 누릅니다.
> 2. **다른 브라우저로 열기**를 누르고 **Chrome**이나 **삼성 인터넷**을 고릅니다.
> 3. 학교에 알려 주신 구글 계정으로 로그인합니다.
> 메뉴가 보이지 않으면 링크를 길게 눌러 복사한 뒤, Chrome이나 삼성 인터넷 주소창에 붙여 넣어 주세요.

**학부모 안내 문구 — 아이폰**

> 카카오톡에서 링크를 누르면 카카오톡 안에서 열려 구글 로그인이 되지 않을 수 있습니다.
> 아래 순서로 열어 주세요.
> 1. 링크를 누른 뒤 화면 오른쪽 아래 **⋯**(또는 공유 버튼)을 누릅니다.
> 2. **Safari로 열기**(또는 다른 브라우저로 열기)를 누릅니다.
> 3. 학교에 알려 주신 구글 계정으로 로그인합니다.
> 메뉴가 보이지 않으면 링크를 길게 눌러 복사한 뒤, Safari 주소창에 붙여 넣어 주세요.

(메뉴 위치·이름은 카카오톡 버전마다 다를 수 있다. K3에서 찍은 사진대로 굵은 글자를 고친다. 학생용은 "학교에 알려 주신 구글 계정" → "학교 구글 계정"으로 바꿔 쓴다. 말투 기준은 `docs/design/writing.md`.)

## F. 결과로 1·2·3안 정하기 (PRD 6.1)

B절 표를 채운 뒤, 아래 표에서 맞는 줄을 찾습니다. 계정 이름은 예시이며 실제 주소는 문서에 적지 않습니다(예: `시험용gmail@gmail.com`).

| 확인한 결과 | 판단 | 다음 할 일 |
| --- | --- | --- |
| 개인 gmail로 `/exec?page=diag` → "접속자 이메일"이 **실제 주소**로 나오고, "다시 확인" 버튼 결과도 **같은 주소** | **1안**: 웹앱 하나로 교사·학생·학부모 모두 운영 | C~E절 계속 진행 |
| 개인 gmail은 **(빈 값)**, 학교 계정(소유자·시험 교사)은 정상 | **2안**: 학생·학부모용 별도 웹앱("접속한 사용자로 실행")을 만들고, 그 웹앱이 `ScriptApp.getIdentityToken()`으로 받은 신원 토큰을 붙여 본 웹앱에 데이터를 요청 | 캡처를 보내 주면 다음 대화에서 2안을 만듭니다 |
