## 앱에서 채울 값(결정 68)
| 칸 | 값 |
| --- | --- |
| 구분(실시·미실시) | 급식 변경 신청의 새 값이 실시(조식 `실시`, 석식 `학사 석식`·`일반 석식`)면 급식실시에 ○, `미실시`면 급식미실시에 ○ |
| 이름 | 학생 이름(출력할 때만 넣는다. 파일을 Drive에 남기지 않는다) |
| 학년ㆍ반 | `N학년 N반 N번` |
