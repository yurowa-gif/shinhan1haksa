# flex(플렉스) 구성원 모바일 첫 화면 — 리콘 지도

작성일 2026-11-21. 방법: replica-recon / replica-entrepreneur 규칙(공개 출처만, 로그인 없음, 긁어 오기 없음, 코드 없음, 지어내지 않음).
**중요한 한계:** 이 세션의 네트워크에서 intercom.help, guide.flex.team, apps.apple.com, help.wheniwork.com, Apple 리뷰 RSS가 모두 막혀 **원문을 한 건도 직접 열지 못했다.** 아래 내용은 전부 웹 검색 결과 요약(검색 엔진이 보여 준 발췌·요약)에서 나왔다. 그래서 인용문은 넣지 않았고, 버튼 이름 등은 "검색 요약에 나온 표현"으로 표시했다. 사진을 못 봤으므로 수치 측정은 없다.

## 1. 범위

- 앱: flex – 올인원 HR 플랫폼(iOS id1535757707, 같은 앱 Android 패키지 team.flex.app). 구성원(직원) 입장, 휴대폰.
- 조각: 첫 화면 [오늘] 탭 → 출퇴근(실시간 근무) → 내 근무(일별 타임라인: 실제 기록 vs 인정 근무) → 휴가 잔여·신청 → 요청 상태 → 알림.
- 관리자 화면(근태 대시보드 운영, 승인 처리, 급여)은 범위 밖. 단, 관리자 행동이 구성원에게 알림으로 오는 부분만 적었다.
- flex 근거로 화면·흐름을 다시 그릴 수 없는 곳은 When I Work 모바일 앱으로 대체하고 "대체(When I Work)"로 표시했다.
- 쓰는 곳: 학교 기숙형 자습 학사의 학생·학부모 포털 "내 상태 한 장"(OUT 0/2, 이번 주 출결, 급식·기숙사 상태, 다음 할 일). UX 패턴만 빌리고 이름·문구·그림은 가져오지 않는다.

## 6. 빈·오류 상태 (근거 있는 것만)

- 근무 화면 월 단위가 안 불러와지던 오류 → 수정됨(flex 앱 변경 이력, 출처 12). 오류 화면 모양은 미확인.
- 위젯 정보가 앱과 안 맞던 오류 → 수정됨(출처 12).
- 연장 근무 시 퇴근 시간 조정이 안 되던 오류 → 수정됨(출처 12).
- 휴가 사용 시간을 항상 한국 시간 기준으로 보이게 고침(검색 요약, 출처 12) → 시간대 혼동이 있었음.
- 위치 권한을 안 줘도 쓸 수 있으나 자동 출퇴근만 제한(출처 12) → "권한 없음" 상태가 존재.
- 회사 설정에 따라 출근 사유 입력이 끼어듦(출처 2) → 같은 버튼이 회사마다 다르게 동작.
- 대체(When I Work): 직원 휴가 신청을 회사가 끄면 직원은 신청 불가, 특정 날짜 신청 막힘(출처 16); 출퇴근 제출이 조용히 실패한다는 리뷰(출처 22).
- 빈 상태(기록 0건, 요청 0건) 화면은 어느 쪽에서도 근거를 못 찾았다.

## 8. 디자인 측정

- 사진을 한 장도 보지 못했다(App Store·도움말 모두 차단). **모든 수치(크기·간격·글자 크기·탭 개수): 측정 불가.**
- 글로 알 수 있는 배치·위계:
  - 첫 화면 이름이 "오늘"이다 → 첫 화면의 단위가 "오늘 하루"이고, 맨 위 주 행동은 출근 버튼 하나.
  - 근무 방식 선택은 위젯(카드) 안으로 접혀 있다 → 기본값(사무실)은 한 번 누름, 예외(재택 등)만 한 단계 더.
  - 사유 입력은 회사 설정일 때만 끼어드는 조건부 단계.
  - 타임라인은 "얇은 선 위에 굵은 막대"를 겹쳐 차이를 그림으로 보이고, 설명은 시각 옆 짧은 글 한 줄.
  - 대체(When I Work): 홈은 카드 묶음이고, 카드를 누르면 목록으로 들어가며, 내가 처리할 것이 목록 맨 위로 온다.
- 색·브랜드·아이콘은 범위에서 뺐다.

## 10. 우리 앱이 피할 것 / 더 잘할 것

**빌려 올 패턴**
1. 첫 화면 단위는 "오늘/이번 주" 한 장. 맨 위에 지금 가장 중요한 숫자 하나(OUT 0/2)와 다음 할 일 하나(예: 시간표 제출). flex의 "오늘" 탭 + 주 행동 하나 구조.
2. 사실과 판정을 나눠 보여 주기. flex의 "실제 기록 vs 인정 근무"처럼, 학생 화면에 "교사 체크(○×△조)"와 "왜 그렇게 됐는지(학원 일정 '학', 사전 특이사항, 미인정 지각 → 자동 1OUT)"를 한 줄 사유로 붙인다. 숫자만 보이면 학부모 민원이 된다.
3. 예외만 한 단계 더. 기본 상태는 바로 보이고, 세부(급식 적용일 계산, 요청 이력)는 카드를 눌러 들어간다.
4. 요청 카드에 상태 배지(접수/확인 중/반영됨/반려) + 반영 예정일. 급식 변경은 "다음 주 월요일부터 반영"처럼 적용일을 꼭 같이 보여 준다(우리 규칙이 적용일 중심이라).

**피할 것**
1. 조용한 실패(대체 리뷰 1위). 실시간이 없는 우리 앱은 제출 뒤 반드시 "저장됨 · 시각" 확인과 실패 시 다시 시도 안내를 보인다. 화면 데이터에는 "○○시 기준" 표시와 새로고침 버튼.
2. 알림 폭탄(대체 리뷰 2위). 학부모에게는 OUT 발생·퇴실 대상·면담 일정 같은 꼭 필요한 것만, 묶어서. 받을 항목을 고를 수 있게.
3. 기능 비대(flex 평가). 학생·학부모 포털은 한 장 + 요청 2~3개로 시작한다.
4. 회사(학교) 설정에 따라 같은 버튼이 다르게 동작하는 것. 우리는 한 학교라 규칙을 고정하고, 다르면 미리 문구로 알린다.
5. 권한 차이로 "보이는 것이 다름"을 숨기지 않기. flex는 실제 기록을 기본으로 최고 관리자만 본다 — 우리는 학생 본인 출결 기록을 학생·학부모가 볼 수 있어야 한다는 점을 서버 권한으로 분명히 하고, 상담 내용은 교사만(학부모에겐 날짜·교사만) 서버에서 거른다. 화면 숨김에 의존하지 않는다.

**학교 맥락에서 더 잘할 것**
- 학부모 자녀 여러 명: 맨 위에 자녀 전환(이름 칩), 마지막 선택 기억(기기 저장은 편의용만). 각 자녀 카드에 OUT 수만 미리 보이게.
- 카카오톡 링크로 열림: 링크 하나로 바로 "내 상태 한 장"이 열리고, 로그인 뒤 원래 보려던 자녀·화면으로 돌아오기. 휴대폰 세로, 큰 글씨.
- 개인정보 최소: 위치 권한·사진 등 요구하지 않는다(flex도 위치는 선택, 서버 미저장). 화면에 다른 학생 정보 0. 학부모에게 교사 메모·상담 내용 미노출.
- 실시간 없음: 출퇴근 버튼 같은 "지금 누르기"는 학생 포털에 넣지 않는다(출결은 교사가 입력). 대신 "다음 할 일" 칸이 주 행동.
- 학기마다 OUT 초기화가 보이게: "이번 학기 OUT 0/2" 처럼 기간을 숫자 옆에 붙인다.

## 11. 확인 못 한 것

- 도움말·App Store·When I Work 도움말 원문을 하나도 열지 못함(네트워크 차단: intercom.help DNS 실패, Apple RSS 응답 없음). 버튼 이름("지금 출근" 등)은 검색 요약에 나온 표현이라 원문과 다를 수 있다.
- 스크린샷 0장: 탭 구성(하단 탭 개수·이름), 근무 중 상태 모양, 퇴근 절차, 타임라인 실제 모양, 모든 수치.
- flex 휴가 잔여·휴가 신청·요청 상태·알림 센터 화면: flex 근거를 못 찾아 When I Work로 대체(S08~S11, F06~F08). S15(잔여 휴가)는 근거 없음.
- 구성원이 일별 타임라인에서 "실제 기록"을 볼 수 있는지(가이드상 기본 권한은 최고 관리자) — 구성원 화면에서 얇은 줄이 보이는지 미확인.
- 홈 위젯이 무엇을 보여 주는지, 푸시 알림 종류 목록, 빈 상태 화면.
- 리뷰 원문·별점 분포·최신 1점 리뷰, 블라인드·커뮤니티 글(검색에 안 잡힘). flex 공식 블로그·유튜브 시연 영상도 검색에 안 잡혀 못 봄.
- 클릭 수는 전부 추정.
