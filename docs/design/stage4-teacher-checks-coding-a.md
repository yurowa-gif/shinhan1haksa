# 4단계 선생님 확인 체크리스트 — 코딩A 기능 (초안)

> **이 문서는 [`stage4-teacher-checks.md`](stage4-teacher-checks.md)(4단계 확인 체크리스트 전체)의 A~F 절로 합쳐졌습니다. 앞으로는 합친 문서만 고칩니다.** 아래는 합치기 전 초안 그대로입니다.

> 코딩A가 만든 기능 다섯 가지(휴일·기간 일괄 설정 **C24**, 근무 기록표 엑셀 **C14b**, 서류 체크리스트 **C27·C27b**, 연락처 **C29**, 방학 중식 **C30**)를 선생님이 실제 Apps Script에서 따라 하며 확인하는 순서입니다. 형식은 `stage3-teacher-checks.md`와 같고, 디자인 세션의 4단계 확인 체크리스트(프로그램 C28 등)와 **겹치지 않게 이 기능들만** 적었습니다. 합칠 때는 절 이름(A~F)만 맞추면 됩니다. 사진 칸은 디자인이 채웁니다.

## 읽는 법

- 한 단계 = **누르는 것 → 이렇게 보이면 통과 → 사진 → 결과(○/×)** 입니다.
- ×가 나오면 **번호 + 한 줄**(예: "D5 학사 교사에게 진행 표가 보임")과 화면 사진을 총괄에게 보냅니다. 앱이 이상한 것이지 선생님이 잘못 누르신 것이 아닙니다.
- 컴퓨터 테스트(`npm test`)가 이미 확인한 것은 "이미 확인됨"으로 적었습니다. 여기서는 **실제 Apps Script에서만 보이는 것**(로그인, 시트 열 끼우기, 휴대폰 화면, 실제 엑셀 열림, 계정별 화면)만 봅니다.
- 이름·번호는 모두 **가짜 데이터**입니다(전화는 `010-0000-xxxx` 형식뿐). 실제 학생·학부모 정보를 쓰는 시험은 없습니다.
- 날짜는 가짜 데이터가 있는 **2027년**을 화면의 날짜 고르기로 고릅니다(오늘 날짜를 바꾸지 않습니다).

| 이름 | 역할 | 쓰는 곳 |
| --- | --- | --- |
| 소유자 | 관리자 + 학사 교사(선생님 계정) | 준비, B~F 전체 |
| 시험1 | 학사 교사(가짜 데이터에서 담당 학생이 있는 계정) | C~F에서 "담당 학생만 보이는지" |
