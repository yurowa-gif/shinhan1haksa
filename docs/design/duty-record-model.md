# 월말 근무 기록표 렌더러 모델 (D7, 제안 — R8·C14와 맞춘 약속)

`printRenderDutyRecord_(model, opts)`(`src/print/DutyRecordHtml.gs`)가 받는 모양이다. **C14(`getDutyRecordFile`)는 `dutyOn_`을 다시 돌리지 않고 R8 `dutyRecord_` 결과만으로 이 모양을 만든다.** 렌더러는 순수 함수라 Apps Script 서비스·현재 시각을 쓰지 않는다(만든 시각은 모델이 준다).

```
{
  month: '2027-03',                       // 필수 yyyy-MM. 틀리면 오류를 던진다
  title: '신한학사 근무 기록표',           // 선택
  termName: '2027 1학기',                  // 선택(머리에 보임)
  closedDates: ['2027-03-02'],            // 선택: 운영 안 하는 날(회색 열)
  teachers: [{
    name: '박선생',
    cells: { '2027-03-01': ['21:30조'], '2027-03-24': ['21:30조', '23:00조'], '2027-03-06': ['단독'] },   // R8 teachers[].dates를 날짜별로 묶은 것
    standby: ['2027-03-07', '2027-03-19']                                                              // R8 standby[].dates (예비 지정만 된 날)
  }],
  swaps: [{ date: '2027-03-05', slot: '단독', from: '이선생', to: '최선생', kind: '대신 근무' }],       // kind 기본 '교대'
  generatedAt: '2027-03-31 18:20',        // 만든 시각(문자열 그대로, 머리말 줄 오른쪽)
  lastChangedAt: '2027-03-20 21:05',      // 그 달 근무표 마지막 변경 시각
  warnings: []                            // 선택: 렌더러가 아래 줄에 그대로 적는다
}
```

- **칸 코드(`cells[날짜]`는 배열)**: R8이 저장한 그대로 `'21:30조'` `'23:00조'` `'단독'`을 준다(렌더러가 끝의 `조`를 떼고 읽는다. 옛 표기 `'단'`은 `'단독'`). 같은 교사가 같은 날 두 조를 맡으면 코드가 둘이고 **둘 다 센다**(칸에는 두 줄로 `21:30`·`23:00`). 하나만 문자열로 줘도 받는다. 알 수 없는 값은 `?`로 보이고 세지 않으며 아래 줄에 개수를 적는다.
- **예비 지정**은 `teachers[].standby` 날짜 배열이다(칸에 `예`). 같은 날짜를 두 번 줘도 한 번 센다. **대신 근무한 날은 R8이 이미 `cells`에 근무로 주고 `standby`에서 뺀다**(두 번 세지 않음, 결정 46).
- **합계는 모델이 주지 않는다.** 렌더러가 칸에서 센다(`printDutyRecordCounts_`). 근무 = 코드 하나당 1회, 예비 지정은 따로. 운영 안 하는 날에 근무가 있어도 근무로 세고(합계 줄에 숫자) 그날 이름을 경고 줄에 적는다. 이 달 밖 날짜는 세지 않는다.
- **`swaps[]`와 `*`**: `to`(실제 근무자) 이름의 그 날짜·그 칸(`slot`)에 `*`를 붙인다. `slot`이 `'예비'`면(예비 감독끼리 바꾼 날) 그 사람의 `예` 칸이 `예*`다. 원래 근무자(`from`)의 칸은 모델에 없다(실제 근무자 기준). **`kind`는 C14가 정한다**: `to`가 그날 그 교사의 예비 지정이었으면 `'대신 근무'`, 아니면 `'교대'`.
- 21:30조·23:00조 수당은 같아(결정 47) 근무 합계를 크게, 조별 횟수는 작은 글자로 보인다. 금액은 계산하지 않는다.
- **쪽 수용량**: A4 가로 한 쪽에 **교사 12명·교대 30건(3단)까지**(긴 이름 8명 × 20건도 한 쪽, `design/preview/duty-record.js`가 확인). 더 많으면 줄이 다음 쪽으로 이어진다(자르지 않는다. 둘째 쪽에는 머리말이 없다). 만든 시각·마지막 변경 시각은 머리말 줄에 있어 첫 쪽에서 보인다.
- **글자 크기 예외**: 31일 달의 날짜 칸 글자는 6pt대로 `print-layout.md`의 7pt 기준보다 작다. 기록표는 책상에서 읽고 손글씨 칸이 아니라서 예외로 둔다(인쇄해 읽기 어려우면 이름 칸·합계 칸 폭을 줄여 날짜 칸을 넓힌다).
- 미리보기: `node design/preview/duty-record.js` → `design/preview/out/duty-record*.png`(기본 + 스트레스 3종, 크로미움 PDF 쪽 수 확인). 가짜 픽스처: `design/preview/duty-record-fixture.js`(D6 시안과 같은 숫자 — 근무 48 = 박8·김8·이7·최9·정8·한8, 예비 지정 11, 교대 3건).
- 이 모양이 R8·C14와 다르면 **이 문서와 렌더러를 맞춘다**(`rules-api.md`가 정해지면 그쪽이 기준).
