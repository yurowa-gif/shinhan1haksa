# 월말 근무 기록표 렌더러 모델 (D7, 제안 — CODING-A와 총괄 동의 전)

`printRenderDutyRecord_(model, opts)`(`src/print/DutyRecordHtml.gs`)가 받는 모양이다. C14(`getDutyRecordFile`)가 R8 `dutyRecord_` 결과로 이 모양을 만든다. 렌더러는 순수 함수라 Apps Script 서비스·현재 시각을 쓰지 않는다(만든 시각은 모델이 준다).

```
{
  month: '2027-03',                       // 필수 yyyy-MM. 틀리면 오류를 던진다
  title: '신한학사 근무 기록표',           // 선택
  termName: '2027 1학기',                  // 선택(머리에 보임)
  closedDates: ['2027-03-02'],            // 선택: 운영 안 하는 날(회색 열, 합계 줄에 —)
  teachers: [{ name: '박선생', cells: { '2027-03-01': '21:30', '2027-03-06': '단독', '2027-03-07': '예비' } }],
  swaps: [{ date: '2027-03-05', slot: '단독', from: '이선생', to: '최선생', kind: '대신 근무' }],   // kind 기본 '교대'
  generatedAt: '2027-03-31 18:20',        // 만든 시각(문자열 그대로)
  lastChangedAt: '2027-03-20 21:05',      // 그 달 근무표 마지막 변경 시각
  warnings: []                            // 선택: 렌더러가 아래 줄에 그대로 적는다
}
```

- **칸 값(`cells[날짜]`)**: `'21:30'` `'23:00'` `'단독'`(금·토·일 근무, 옛 표기 `'단'`도 받는다) = **실제 근무자**의 근무. `'예비'` = 예비 지정만 된 날. 빈 칸은 키를 두지 않는다. 그 밖의 값·이 달 밖 날짜는 세지 않고 아래 경고 줄에 개수를 적는다.
- **합계는 모델이 주지 않는다.** 렌더러가 칸에서 센다(`printDutyRecordCounts_`). 근무 = 21:30 + 23:00 + 단독, 예비 지정은 따로(결정 46). 그래서 **예비 감독이 대신 근무한 날은 `cells`에서 그 교사의 칸을 `'단독'`(근무)으로 주고 `'예비'`로 주지 않는다** — 그러면 근무로만 세고 예비 지정에서는 빠진다.
- **교대로 칸이 바뀐 사람**: `swaps[].to` 이름의 그 날짜 칸에 `*`를 붙인다. 원래 근무자(`from`)의 칸은 모델에 없다(실제 근무자 기준).
- 21:30조·23:00조 수당은 같아(결정 47) 근무 합계를 크게, 조별 횟수는 작은 글자로 보인다. 금액은 계산하지 않는다.
- 쪽: A4 가로 한 쪽(교사 12명·교대 10건 정도까지). 더 많으면 줄이 다음 쪽으로 넘어간다(자르지 않는다). `docs/design/print-check.md`와 별개로 선생님이 인쇄해 실제 근무자와 대조한다(plan ⑤ 확인).
- 미리보기: `node design/preview/duty-record.js` → `design/preview/out/duty-record.png`·`.pdf`(크로미움 PDF 1쪽 확인). 가짜 픽스처: `design/preview/duty-record-fixture.js`(D6 시안과 같은 숫자 — 근무 48 = 박8·김8·이7·최9·정8·한8, 예비 지정 11, 교대 3건).
