# 식수 집계 출력 모델 (D8, 제안 — C19와 맞출 것)

`printRenderMealCounts_(model, opts)`(`src/print/MealCountsHtml.gs`)가 받는 모양이다. C19(`getMealCountsPdf`)가 R12 `mealCountsOn_` 결과를 그대로 `counts`에 넣고 머리말·참고 값을 더해 만든다. 렌더러는 순수 함수라 Apps Script 서비스·현재 시각을 쓰지 않는다(만든 시각은 모델이 준다).

```
{
  date: '2027-03-03',                      // 필수 yyyy-MM-dd (틀리면 오류를 던진다). 요일은 날짜에서 구한다(ymdWeekdayKo_)
  title: '신한학사 식수 집계',              // 선택
  termName: '2027 1학기',                   // 선택
  operating: true,                         // 선택: 그날 자습 운영 여부(참고용 한 줄, false면 "이 날은 자습 운영 안 함(참고)")
  counts: <mealCountsOn_ 결과 그대로>,      // {groups, afterLeaveHallDinner, unknownGroup, warnings}
  docUnsubmitted: 2,                       // 선택: 서류 미제출 학생 수(이름은 출력물에 쓰지 않는다)
  preparedBy: '관리자', generatedAt: '2027-03-03 17:40'   // 선택: 작성·만든 시각 칸
}
```

- **행** = `counts.groups`의 줄을 `여N → 여 합계 → 남N → 남 합계 → N학년 → 전체` 순으로(모르는 이름은 끝에, 버리지 않는다). **열** = 학사 / 기숙 / 비기숙 / 조식 / 석식 학사 / 석식 일반 / 석식 계(= 학사 + 일반, 렌더러가 더한다).
- **렌더러는 숫자를 바꾸지 않는다.** 다만 합계를 검사한다: 학사 = 기숙 + 비기숙, 여·남 합계 = 부분 합, N학년 합계 = 여N + 남N, 전체 = 여 합계 + 남 합계. 어긋나면 아래 경고 줄에 어느 줄·어느 열인지 적는다("합계가 맞지 않습니다 — 전체: 학사 ≠ 부분 합"). 숫자가 아닌 칸은 `?`로 보인다.
- 아래 줄: "신청 기준 인원입니다(결석·외박은 반영하지 않습니다)", "퇴실 후 석식 유지 N명"(`afterLeaveHallDinner`), "서류 미제출 N명"(`docUnsubmitted`가 있을 때), 경고 — **한 줄에 하나**씩. `counts.warnings` 중 `unknownGroup` 학생을 가리키는 개별 문장(R12 형식 "<학생 id> 학생의 …")은 **급식실에 내는 종이에 싣지 않고** "성별·학년을 알 수 없는 학생 N명은 어느 줄에도 넣지 않았습니다." 한 줄로만 요약한다(학생 id·이름은 교사 화면 몫). 합계가 안 맞는 줄은 "합계가 맞지 않습니다 — 전체: 학사 ≠ 부분 합"처럼 따로 적는다.
- **숫자 읽기**: 0 이상 정수와 숫자만 든 문자열(`'2'`·`' 3 '`)만 숫자로 받는다. 빈 문자열·null·true·소수·음수·글자 섞인 값은 칸에 `?`로 찍고(0으로 바꾸지 않는다), 석식 계는 학사·일반 중 한쪽이 `?`면 `?`다. 서류 미제출·퇴실 후 석식 유지도 같은 규칙(`docUnsubmitted`가 null·undefined면 그 줄을 쓰지 않는다).
- 쪽: A4 세로 한 쪽(여백 14mm → 인쇄 폭 515.9pt라 내용 폭은 **515pt**. 줄 12개 + 4학년 같은 추가 줄이 있어도 한 쪽). 모든 글자는 7pt 이상. 합계 줄은 굵은 글씨 + 회색 바탕(흑백 인쇄). 아래에 작성자·만든 시각과 "급식실 확인(서명)" 칸이 있는 **임시 양식**이다(급식실 양식을 받으면 맞춘다).
- 미리보기: `node design/preview/meal-counts.js`(크로미움 PDF 1쪽 + PNG). 가짜 픽스처 `design/preview/meal-counts-fixture.js`는 D6 시안·관리자 홈과 같은 숫자(학사 30·기숙 24·비기숙 6·조식 23·석식 학사 27 + 일반 3, 퇴실 후 석식 유지 1명).
- R12의 `counts` 모양이 바뀌면 이 문서와 렌더러를 맞춘다(`docs/contracts/rules-api.md`가 기준).
