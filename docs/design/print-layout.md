# 출석부 A4 가로 인쇄 레이아웃 (D4.1: 한 장에 1층 + SA1~6실)

코드: `src/print/AttendanceSheetHtml.gs` — `printRenderSheet_(model, opts)`(HTML 문서 문자열), `printSheetPlan_(model, opts)`(배치 진단).
모델은 `docs/contracts/sheet-model.md`. 미리보기·쪽 수 확인은 `node design/preview/sheet.js`(크로미움으로 A4 가로 PDF를 만들어 쪽 수·넘침을 본다, 결과는 `design/preview/out/`).
픽스처는 `node design/preview/fixtures.js`가 만든다(`design/fixtures/sheet-model.{mon_thu,fri,sat,sun}.json`, 가짜 좌석 배치 + 가짜 학생 30명 반복).
근거 결정: decisions 32(일요일 4칸)·33(기존 양식은 복제 대상이 아님, 실제 공간과 맞아야 하는 것만 지킴)·34(1층 + SA1~6실을 A4 한 장에).

## 지키는 것 / 바꾼 것

- **지킨다(실제 공간):** 1층 세로 8줄 · 줄별 좌석 19·17·18·19·19·20·20·14(146석) · 홑줄 | 짝줄 | 짝줄 | 짝줄 | 홑줄(교사가 교실을 걸으며 보는 순서). 줄 구조는 모델 `cells`의 열 배치에서 읽는다(통로 열이 사이에 있으면 다른 줄 묶음, 없으면 짝줄). SA실도 방마다 세로 2줄.
- **바꾼다(더 낫게):** 이름 칸을 표시 칸 **위**로(줄 너비 절약), 줄 머리에 공석/좌석, 머리말 요약, 오늘 특이사항 목록, 메모 칸, SA실을 같은 장에. (OUT 표시는 넣지 않는다: 결정 36, 출석부에는 학년·이름만.)

## 쪽 구성

```
┌ 신한학사 출석부  2027년 3월 3일(수)  자습 18:00–24:00            근무 ____ ____  예비 ____ ┐
│ 재적 176 · 공석 21 · 특이사항 20명 · 학 25 · 가 16 | 표시 칸 ①18–20 ②20–22 ③22–24 | 범례     │
├ 1층 자습실 · 146석 ───────────────────────┬ SA1 남 │ SA2 남 │ SA3 여 ┤  ← 일요일(4칸)은 SA 2열×3행
│ 8줄(홑 | 짝×3 | 홑), 줄마다 위에 공석/좌석     │ SA4 여 │ SA5 여 │ SA6 여 │
│ 좌석 = [이름]                                  ├ 오늘 특이사항 20명 ………………………┤
│        [표시][표시][표시]                       │ 이름 ①② 약어 …(2열)                │
│                                                │ [무단·기타 메모 칸]                 │
└ 자리 배정 안 됨 …                                                                    ┘
```

- **머리말(두 줄):** 첫 줄 제목·날짜·요일·자습 시간·근무(월~목 2칸, 그 밖 1칸)·예비(금·토·일, 또는 이름이 있을 때만) / 둘째 줄 인원 요약(**재적 = 자리 있는 학생 + 자리 없는 학사생**·공석·특이사항 학생 수·학·가)·표시 칸 순서·범례(`model.legend` 그대로: 조 조퇴(사유는 메모 칸에) — 결정 38).
- **좌석 칸:** 위 이름("1. 이름"/"공석" — 학년·이름만, OUT 표시 없음), 아래 표시 칸 n개(왼쪽→오른쪽 ①②③④). 미리 채운 칸(학·가·특이사항·정상 종료)은 진한 회색(#d4d4d4), 공석은 연한 회색(#f4f4f4), 흰 칸만 근무교사가 ○ × △ 조를 쓴다. **조퇴 사유는 학생 칸이 아니라 메모 칸**(결정 38). 배경이 인쇄되도록 `print-color-adjust: exact`.
- **줄 머리:** 줄 위에 "19석 공2"(좌석 수·공석 수 — 3/18처럼 날짜로 읽히지 않게).
- **SA실 열 수:** 3열 → 2열 → 1열 순으로, 표시 칸이 목표 너비(14.5pt)를 넘는 가장 큰 열 수를 고른다. 평일·금·토(3칸)는 3열(목록 칸 넓음), 일요일(4칸)은 2열.
- **오늘 특이사항 목록:** `EXC` 표시가 있는 학생(학년→이름 순) "이름 ① 병결 외 1 · ②③ 병결"(어느 블록이 어느 약어인지). 사유 메모는 없다. 앞면 목록 칸에 다 들어가면 앞면만, 넘치면 앞면에는 일부 + 뒷면에 전체.
- **메모 칸:** "메모 (조퇴 사유·무단 사항)"는 요일과 상관없이 앞면에 늘 있다(일요일 포함).
- **자르지 않는다:** 한 장에 다 못 담으면 내용을 자르지 않고 ① SA실을 가능한 열 수(3→2→1)로 다시 배치 ② 그래도 모자라면 넘는 공간·행을 **뒷면에 이어서** 보내고 앞면 아래에 "※ …뒷면에 이어집니다" 경고 줄을 둔다. 자리 배정 안 된 학생은 앞면 아래 두 줄까지, 나머지는 "외 N명(뒷면에 전체)"와 뒷면 전체 목록(여러 쪽 가능). 특이사항 목록도 뒷면이 여러 쪽이 될 수 있다.
- 기둥은 회색 바탕 + 빗금 + "기둥", 비상문·창문은 점선 칸 + 글자. 흑백 인쇄에서도 글자로 구분된다.

## 최소 크기와 근거

| 항목 | 값 | 근거 |
| --- | --- | --- |
| 표시 칸 너비 | 목표 14.5pt(5.1mm), 하한 12.8pt(4.5mm) | 볼펜으로 ○ × △ 조 한 글자를 쓰는 데 필요한 너비 4.5mm 이상(지름 3mm 안팎 글자 + 여백). 14.5pt면 7pt 글자 두 개("병결"·"무지")가 한 줄에 들어간다 |
| 표시 칸 높이 | 약 5.2mm(14.7pt) | 7pt 글자 두 줄("정상 / 종료") 또는 손글씨 한 글자. 2줄까지는 행을 늘리지 않는다 |
| 좌석 한 줄 높이 | 약 8.1mm(22.8pt), 하한 21.5pt(이름 8.5 + 표시 칸 13) | 1층 20줄 + 머리 + 아래 줄이 A4 가로 높이(192mm)에 들어가는 최대 |
| 이름 글자 | 9pt(1층 줄 너비 54pt에 "2. 신구름"이 한 줄). 아주 긴 이름만 7pt까지 줄이고 그래도 넘치면 줄바꿈(그 행만 높아짐) | 팔 길이(약 50cm)에서 읽히는 하한을 8pt로 봤다. 총괄이 예로 든 6.5pt보다 크게 |
| 표시 칸·목록 글자 | 7pt 이상 | 같은 거리에서 "학·가·병결"이 읽히는 하한. 머리말 요약·범례도 7pt |
| 줄 너비 | 평일·금·토 54.5pt(표시 칸 18.2pt = 6.4mm), 일요일 64pt(16pt = 5.6mm) | 1층 8줄 + SA 3열(6줄) 또는 2열(4줄) + 통로·간격을 796pt에 넣고 남는 폭을 줄 수로 나눈 값. 블록 5개처럼 표시 칸이 4.5mm 아래가 되면 1열로 바꾸고 모자란 공간은 뒷면에 이어 붙인다 |

위 값은 크로미움 인쇄로 쪽 수·넘침을 확인한 값이며(`node design/preview/sheet.js`는 평범한 4종 + 적대적 입력 13종 — 긴 이름·긴 공석 문구·블록 5개·1층 21행·3글자 약어·미배정 30/180명·특이사항 120명·공간 순서 바뀜·공간 없음·긴 공간 이름·근무자 이름이 배열이 아님·일요일+120명 — 을 그려 **어느 쪽·어느 칸이든 내용이 잘리면 실패**한다), **실제 손글씨로 쓸 만한지는 선생님이 인쇄본에 써 보고 확인**한다(print-check.md 28~31). 모자라면 `PRINT_MARK_MIN_W_PT`·`PRINT_MIN_PITCH_PT`를 바꾼다.

## PDF 변환기에서 확인할 것(C0 결과 후)

- 표·인라인 CSS만 쓰고 flex·grid·웹폰트·외부 리소스는 없다. 글꼴은 `Nanum Gothic` → `Malgun Gothic` → sans-serif. 칸 합치기(`colspan`·`rowspan`)를 쓴다.
- 크롬에서는 한 장씩 나오지만 Apps Script 변환기는 크롬이 아니다. 아래가 달라질 수 있어 C0(선생님 실행) 결과로 확인한다: ① 쪽 수(앞면 1장) ② 한글 글꼴 ③ 기둥 빗금(`repeating-linear-gradient`을 못 그리면 회색 바탕 + "기둥" 글자) ④ 행 높이(변환기가 테두리를 다르게 계산하면 아래가 잘릴 수 있음 → `PRINT_ROW_SLACK_PT`·`PRINT_SLACK_PT`) ⑤ 글자 단위 줄바꿈(`word-break:break-all`)과 `rowspan` 처리.
- B안(시트 내보내기)이 정해지면 열 너비·글꼴·테두리를 `docs/design/print-sheet-spec.md`로 따로 낸다(HTML 렌더러는 화면 미리보기용으로 남긴다).

## 모델 선택 필드(계약 제안, 없어도 동작)

- `standbyNames`(문자열 배열): 머리말 "예비". 없으면 빈칸(총괄 승인, sheet-model.md에 총괄이 추가).
- `occupant.outLevel`(OUT 표시)은 제안을 철회했다(결정 36). 인쇄물에는 학년·이름만 싣는다.
- 요약 수치와 특이사항 목록은 `cells`/`marks`에서 렌더러가 계산하므로 모델 필드가 필요 없다.
