# 출석부 A4 가로 인쇄 레이아웃 (D4 · D4.1 실제 시트 모양)

코드: `src/print/AttendanceSheetHtml.gs` — `printRenderSheet_(model, opts)`(HTML 문서 문자열), `printSheetPlan_(model, opts)`(쪽마다 크기·넘침 진단).
모델은 `docs/contracts/sheet-model.md`(변경 없음). 미리보기·쪽 수 확인은 `node design/preview/sheet.js`(크로미움으로 A4 가로 PDF를 만들어 공간 수와 쪽 수가 같은지 본다, 결과는 `design/preview/out/`).
픽스처는 `node design/preview/fixtures.js`가 만든다(`design/fixtures/sheet-model.{mon_thu,fri,sat,sun}.json`, 가짜 좌석 배치 + 가짜 학생 30명 반복).
기준 모양은 선생님이 주신 실제 출석부(`docs/reference/real-layout-2025.md` 4.1)다.

## 모양 (실제 출석부와 같게)

- 공간마다 `<section class="page">` 하나 = A4 가로 한 장(`@page { size: A4 landscape; margin: 8mm }`, 쪽 폭 796pt × 높이 544pt).
- **머리말:** 가운데 "신한학사 출석부", 오른쪽 "2027년 3월 3일(수)", 왼쪽 공간 이름과 "근무: ____"(근무교사 이름 `dutyNames`가 없으면 밑줄). 둘째 줄에 "표시 칸(왼쪽→오른쪽) ①18–20 ②20–22 ③22–24 | 범례". 블록 시간은 칸마다 쓰지 않고 여기에 한 번만 쓴다.
- **세로 줄:** 격자의 좌석 열 하나 = 세로 줄 하나. 1층은 `홑줄 | 짝줄 | 짝줄 | 짝줄 | 홑줄`(줄별 좌석 수 19·17·18·19·19·20·20·14 = 146석). 통로 열이 없이 붙은 두 줄이 짝줄이다. 이 줄 구조는 모델 `cells`의 열 배치(통로 열이 사이에 있는지)에서 읽는다 — **좌석표를 가져올 때(C6) 짝줄 사이에는 통로 열을 넣지 않고 줄 사이에는 하나씩 넣어야 한다.**
- **좌석 하나 = 표 한 줄:** `[이름 칸][표시 칸 × 블록 수]`.
  - 이름 칸: "1. 이름"(굵게) 또는 "공석"(연한 회색).
  - 표시 칸: 미리 채운 글자(학·가·병결·정상 종료)는 회색 바탕, 빈칸은 흰색(근무교사가 ○ × △ 조를 손으로, 아래쪽 여백에 사유).
  - **짝줄은 이름 칸이 등을 맞대고 표시 칸이 바깥쪽**, 홑줄은 표시 칸이 가운데(통로) 쪽이다. 표시 칸 순서는 어느 줄이든 왼쪽→오른쪽이 ①②③(④).
- **줄 머리 칸:** 줄마다 위에 "공석 수/좌석 수"(예 5/19). 앞 숫자가 공석 수라는 것은 원본에서 읽은 추정이다(ASSUMPTION, print-check.md 확인).
- **기둥**은 회색 바탕 + 빗금 + "기둥", **비상문·창문**은 점선 칸 + 글자. 흑백 인쇄에서도 글자로 구분된다.
- 일요일은 블록이 4개라 표시 칸이 4칸이다(원본 시트는 3칸이라 확인 필요: print-check.md 4a). 줄 너비 약 97pt에 이름 칸 약 39pt를 빼면 표시 칸이 약 14.5pt라, 7pt 글자 두 개("병결")가 한 줄에 겨우 들어가거나 한 글자씩 두 줄로 나뉜다(크롬 인쇄에서 나뉘는 것을 확인). 읽기는 되지만 보기 좋지 않으니 실제 일요일 양식을 보고 정한다.
- 아래 줄: 첫 쪽에만 "자리 배정 안 됨 3. 박다솜 …".
- 특이사항(`EXC`)은 굵게, 학·가·정상 종료는 보통 굵기.

## 크기 규칙

| 항목 | 값 |
| --- | --- |
| 글자 | 이름 8pt 이상, 표시 칸 7pt 이상(머리말 8~16pt). 칸이 크면(SA실) 최대 2.2배까지 키운다 |
| 줄 너비 | 1층은 줄 하나가 약 97pt(이름 칸 약 40pt + 표시 칸 3개 약 19pt씩, 일요일 4개면 약 14.6pt씩). 통로 열은 4pt, 기둥·문·창만 있는 열은 28pt. 줄 최대 190pt |
| 행 높이 | 기준 22.5pt(7pt 글자 3줄). 남는 높이를 행 수로 나눠 키운다. 한 칸 안 줄바꿈은 3줄까지 행을 늘리지 않는다 |
| 긴 글자 | 표시 칸보다 길면(예: "정상 종료"가 두 줄) 글자 단위로 줄바꿈한다. 3줄을 넘으면 그 행만 높아진다. 글자는 7pt 아래로 줄이지 않는다 |
| 빠듯하면 | 줄바꿈이 많아 모자라면 칸 높이를 0.9배까지 줄인다(`warnings`에 "빠듯합니다"). 그래도 안 들어가면 `fits=false` |
| 너무 좁으면 | 표시 칸이 13pt 미만이면 통로 열(없으면 가운데)에서 좌우 두 쪽(최대 네 쪽)으로 나눈다. 머리말 공간 이름 뒤에 "(1/2)" |
| 행이 너무 많으면 | 나누지 않고 `fits=false`로 알린다(C7이 화면에 경고) |

`fits=false`·"빠듯합니다"는 C7이 미리보기 경고로 보여 줄 수 있다(`printSheetPlan_`).

## PDF 변환기에서 확인할 것(C0 결과 후)

- 표·인라인 CSS만 쓰고 flex·grid·웹폰트·외부 리소스는 없다. 글꼴은 `Nanum Gothic` → `Malgun Gothic` → sans-serif.
- 크롬에서는 한 장씩 나오지만 Apps Script 변환기는 크롬이 아니다. 아래가 변환기에서 달라질 수 있어 C0(선생님 실행) 결과로 확인한다: ① 공간마다 한 장인지 ② 한글 글꼴 ③ 기둥 빗금(`repeating-linear-gradient`을 못 그리면 회색 바탕 + "기둥" 글자로만 보인다) ④ 행 높이(변환기가 칸 테두리를 다르게 계산하면 마지막 행이 잘릴 수 있음 → `PRINT_ROW_SLACK_PT` 조정) ⑤ 글자 단위 줄바꿈(`word-break:break-all`)이 먹는지(안 먹으면 "정상 종료"가 칸을 넘칠 수 있음).
- B안(시트 내보내기)이 정해지면 열 너비·글꼴·테두리를 `docs/design/print-sheet-spec.md`로 따로 낸다(HTML 렌더러는 화면 미리보기용으로 남긴다).
