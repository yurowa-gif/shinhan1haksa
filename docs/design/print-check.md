# 출석부 인쇄 확인표 (D5)

선생님이 **기존 출석부 인쇄본(또는 사진)과 새 출석부를 나란히 놓고** 볼 항목입니다. 한 항목씩 ○/×로 표시하고, ×가 있으면 어디가 어떻게 다른지 적어 총괄에게 주세요. 이 표는 C7(출석부 PDF) 완료 체크리스트에 그대로 들어갑니다.

준비물: 같은 날짜의 기존 출석부 1장(1층), SA실 1장, 새 앱의 같은 날짜 PDF(평일·금·토·일 4일). 이름은 가려도 됩니다(앱 안 이름은 가짜 데이터).
방법: 휴대폰에서 홈 → 오늘 출석부 → PDF 열기(버튼 두 번). 인쇄할 때는 **A4 가로, 배율 100%(실제 크기), 여백 기본**으로 합니다.

## 결과 적는 법

- 모두 ○면 "인쇄 확인 통과"라고 총괄에게 알립니다.
- ×는 **번호 + 한 줄**로 적습니다(예: "3번 1층 아래 줄이 잘림", "29번 정상 종료가 두 줄로 나뉨"). 사진이 있으면 이름을 가리고 첨부합니다.
- 기존 출석부와 **일부러 달라진 것**(블록 시간이 머리말에만 있음, 사유 메모 없음, 공석 표기)은 ×가 아니라 "차이 확인"으로 적어 주세요. 총괄이 계속 둘지 정합니다.
- 변환기에서 마지막 행이 잘리거나 기둥 빗금이 안 보이면 코딩 세션과 디자인 세션이 `docs/design/print-layout.md`의 값을 조정합니다.
