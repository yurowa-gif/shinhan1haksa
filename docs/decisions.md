## 해석(총괄이 답변에서 읽어 낸 것 — 다르면 고친다)

- 7번·12번을 합쳐서: 사전 특이사항 입력과 출결 결과 격자는 **출결 담당**(역할 `attendance`)이 학사생 전체를 맡는다. 학생별 담당교사와 담임은 특이사항을 보고 "요청"을 남긴다. 근무교사는 종이 출석부에 ○·×·△·조를 표시하고, 앱에서는 그날 출석부·특이사항을 본다.
- 6번: 예비 감독은 지정만으로는 근무 기록표(수당)에 들어가지 않는다. 실제로 근무하면 교대로 기록되어 들어간다. (ASSUMPTION, 13절에 질문으로 남김)
- 10번: 자동 1OUT의 입력자는 출결 담당, 적발 교사는 그날 근무교사로 채운다. 출결 기록이 취소되면 연결된 OUT도 함께 취소된다.
